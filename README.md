# PhotoCull Android

An Android photo-review app concept for swipe-based culling.

## Planned behavior
- Swipe right to keep a photo.
- Swipe left to mark a photo for review/deletion.
- Undo decisions and export a decision list.

## Google Photos limitation
Third-party apps cannot generally delete or reorganize arbitrary existing items in a user's Google Photos library through the current Google Photos APIs. A cloud workflow must respect current Picker/API scopes and may require the user to finish deletion in Google Photos.
